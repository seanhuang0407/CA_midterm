# AI usage

Codex assisted with model inspection, integer kernel code, export/reference scripts,
Spike setup, profiling scripts, verification, and documentation. Model weights were
not generated by AI; they were downloaded from the pinned upstream LiteRT repository.
Results in results/ are actual local runs, not estimated custom-instruction results.
Students should review and understand all code before submission and disclose this
assistance according to the course's policy.

The subsequent ISA work also used Codex to implement the two project-local Spike
instructions, opcode/disassembler patch, C wrappers, prepared software controls,
Python arbitrary-precision test vectors, trap/alias tests, and measured ablations.
All reported ISA results were executed on Spike; they are not RTL/PPA estimates.
